# Changelog

## 0.1.0

* **`WincheFlutter.initializeApp`**: `Winche.initializeApp` for Flutter, with a folder on the device for the SDKs'
  data (`WincheFlutter.defaultDirectory`).
* **`WincheFlutter.select`**: the options for the platform this runs on, for the `DefaultWincheOptions` that
  `winche configure` writes.
* Re-exports `winche_core`.
